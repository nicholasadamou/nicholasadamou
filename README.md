#### 🧰 Pinned work — the throughline

Three tools → the methodology → proof of range.

| Logo | Project | Why it's here |
|:---:|---|---|
| <img src="https://raw.githubusercontent.com/smeltery/agnt/main/agnt-site/assets/app-icon.png" width="24" height="24" alt="agnt logo" /> | **[agnt](https://github.com/smeltery/agnt)** | **Take your agents with you.** Send prompts, follow progress, and review changes from your phone or browser while coding agents and repositories stay on your Mac or Linux machine. |
| <img src="https://raw.githubusercontent.com/smeltery/trellis/main/fork/branding/prod/trellis-logo.svg" width="24" height="24" alt="Trellis logo" /> | **[Trellis](https://github.com/smeltery/trellis)** | **Give agent work a home.** A local-first web and desktop workspace for organizing projects and threads, reviewing changes, and working with terminals and Git worktrees. |
| <img src="https://raw.githubusercontent.com/smeltery/slipway/main/assets/logo.svg" width="24" height="24" alt="Slipway logo" /> | **[Slipway](https://github.com/smeltery/slipway)** | **Let agents test Mac apps.** Deploys builds to a headless Mac VM so coding agents can launch, inspect, screenshot, and interact with apps without taking over your screen. |
| <img src="https://raw.githubusercontent.com/smeltery/porthole/main/assets/logo.svg" width="24" height="24" alt="Porthole logo" /> | **[Porthole](https://github.com/smeltery/porthole)** | **See what agents are doing.** A native Mac app that shows test VMs live, groups commands by agent and chat, and flags overlapping sessions. |
| <img src="https://raw.githubusercontent.com/smeltery/fugue/main/site/public/favicon.svg" width="24" height="24" alt="fugue logo" /> | **[fugue](https://github.com/smeltery/fugue)** | **Make agent sessions disposable.** Runs AI coding agents in ephemeral, isolated environments that keep session state from lingering. |
| <img src="https://raw.githubusercontent.com/smeltery/prr/master/assets/logo.svg" width="24" height="24" alt="prr logo" /> | **[prr](https://github.com/smeltery/prr)** | **Bring agents into code review.** Reviews pull requests and local branches, verifies findings, and produces actionable feedback organized by severity. |
| <img src="https://raw.githubusercontent.com/smeltery/distill/master/website/public/favicon.svg" width="24" height="24" alt="distill logo" /> | **[distill](https://github.com/smeltery/distill)** | **Give agents useful context.** Turns technical books and documentation into structured Markdown repositories that coding agents can consume. |

Useful context → isolated execution → verified feedback → repeatable workflows.
